# Shared Documentation

This directory contains references and documentation that apply across multiple labs or projects.

Suggested contents:

- `architecture/` — shared architecture diagrams and high-level system views.
- `network-design/` — CIDR allocation plans, naming conventions, network patterns, and design references.
- `decisions/` — Architecture Decision Records (ADRs): context, options, decision, and consequences.
- `troubleshooting/` — recurring issues and diagnostic procedures that are useful across labs.

Lab-specific implementation details and test results belong in the relevant lab's own README. Avoid duplicating the same information in multiple places.
